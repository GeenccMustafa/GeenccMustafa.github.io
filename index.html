Agents & Agentic Workflows

Multi-step LLM agents with tool use, memory and reasoning. I also build query-to-agent routing and stateful workflows that coordinate several specialist agents.

Deployment to Production

Containerised microservices on self-hosted and cloud GPU infrastructure (Docker, FastAPI, Celery/Redis, vLLM). Every service runs with CI/CD and is monitored for quality, latency and cost.

Document AI & OCR

Evaluation & Guardrails

LLM Fine-Tuning

PEFT / QLoRA with TRL for domain-specific document intelligence. Each tuned model is benchmarked against proprietary APIs on accuracy, latency and cost.

Experience
